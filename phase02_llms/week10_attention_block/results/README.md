# Results And Artifact Storage

No binary artifact is stored here; the week's measured evidence lives in
[RESULTS.md](../RESULTS.md) and [RUN_LOG.md](../RUN_LOG.md). For a future run,
retain a small dated bundle here with resolved settings, source identities, test
summaries, parameter counts, timings, and a note explaining limitations.

This week produces no trained weights. Small fixtures, recorded commands, and an
optional illustrative attention-weight PNG may be tracked when their purpose is
explicit. Any model checkpoints belong outside Git under `AI_ROADMAP_DATA`,
following the [data policy](../../../DATA_PLAN.md).

Preserve failed runs and keep estimates separate from measurements. A directory
or placeholder table does not establish that a check passed.
